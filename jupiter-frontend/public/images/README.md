# Public Images Folder (`public/images/`)

Put all your website images (hero banner, machinery photos, block products, logos) in this folder.

## How to use images in React:
Any image placed in this folder can be used directly with `/images/your-image-name.jpg`.

### Example:
If you add an image named `hero-banner.jpg` into `public/images/hero-banner.jpg`, you can use it in your code as:

```tsx
<img src="/images/hero-banner.jpg" alt="Hero Banner" />
```

Or as CSS background:
```css
background-image: url('/images/hero-banner.jpg');
```
